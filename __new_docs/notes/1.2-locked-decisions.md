# 1.2 Locked Decisions

Status: normative index for the 1.2 addendum.

This file exists to prevent AI agents and implementation agents from importing syntax or semantics from familiar languages.

## Consequence words

```text
known   compiler-known / known during compilation
fixed   fixed storage / fixed placement / fixed lifetime
pin     temporary pinning action for address stability
unsafe  unchecked/manual obligation boundary
```

`static` and `pinned` are not source keywords.

## Staging and sigils

```text
#       datum literal/pattern family
$       template literal interpolation
~       syntax quote / in-template splice
splice  explicit source-position insertion
```

Rules:

```text
~ by itself is not compile-time.
known makes an expression compiler-known.
Syntax values are allowed as runtime values when runtime syntax/compiler support exists.
splice requires known syntax because it changes the program being compiled.
```

## Quote family

The staged syntax family is locked at the semantic level:

```musi
~(expr)
~type(type)
~pat(pattern)
~decl(declaration)
~decls(declarations)
```

Inside a quoted syntax template, `~x` splices a syntax value into the quoted syntax.

Outside a quoted syntax template, use `splice x;` for source-position insertion.

## Type names

```text
Any     runtime top value carrier
Unknown checker/frontend imprecision, not verified bytecode
Empty   bottom / uninhabited / unreachable
```

`Dynamic` is not the Musi type name.

## Inference

```text
omitted annotation -> Unknown
Unknown must be solved by inference/evidence or become explicit Any
implicit Any is not allowed by default
SEIL/SEBC must not contain Unknown
```

## VM stack

```text
Musi source -> Musi Core -> SEIL -> SEBC -> SEAM
```

```text
SEAM = Stack Effect Abstract Machine
SEIL = Stack Effect Intermediate Language
SEBC = Stack Effect Bytecode
```

SEIL and SEBC syntax/encoding are not locked by this addendum. Only their role boundaries and constraints are locked.
