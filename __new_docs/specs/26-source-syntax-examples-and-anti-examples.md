# 26. Source Syntax Examples and Anti-Examples

Status: normative examples for agents. Valid examples show admitted source shape. Invalid examples must not be generated by agents.

## Bindings

Valid:

```musi
let x := 1n32;
let mut count := 0n32;
count := count + 1n32;
```

Invalid:

```musi
var x = 1;
const x = 1;
def f(x) { x }
fn f(x) => x;
```

## Functions

Valid:

```musi
let id[T](value : T) : T := value;

let add(x : Int32, y : Int32) : Int32 := x + y;

let add(x, y) := x + y;
```

The last form is valid only if inference/evidence solves the omitted types. It must not silently become `(Any, Any) -> Any`.

Invalid:

```musi
function add(x, y) { return x + y; }
fun add(x, y) := x + y;
fn add(x, y) -> x + y;
```

## Bodies and sequencing

Valid:

```musi
let f(x : Nat32) : Nat32 := (
  let y := x + 1n32;
  y * 2n32
);
```

Invalid:

```musi
let f(x : Nat32) : Nat32 := {
  let y := x + 1n32
  return y * 2n32
};
```

Newlines do not separate expressions. Semicolons are semantic sequence/discard markers.

## Conditionals

Valid:

```musi
let label := "adult" when age >= 18n32 else "minor";

let maybeIndex := index when found;
```

Invalid:

```musi
if age >= 18 then "adult" else "minor";
if (age >= 18) { "adult" } else { "minor" };
```

## Match

Valid:

```musi
let result := match value (
| .Some(x) => x
| .None => fallback
);
```

Invalid:

```musi
switch value {
case Some(x): x
case None: fallback
}
```

## Datums

Valid:

```musi
let pair := #(key, value);
let list := #[1n32, 2n32, 3n32];
let rec := #{x := 1n32, y := 2n32};
```

Invalid:

```musi
#[derive(Show)]
```

Attributes do not use `#`.

## Attributes

Valid:

```musi
@name
@name(...)
```

Raw FFI candidate/existing surface:

```musi
@foreign(abi := .cdecl, name := "foreign_name")
let f(x : T) : U;
```

Invalid:

```musi
foreign {
  fn f(x: T) -> U;
}
```

## Consequence words

Valid:

```musi
known let bits := 64n64;
fixed mut counter := 0n32;

pin buffer as p (
  unsafe (
    foreignWrite(p.ptr, p.len);
  );
)
```

Invalid:

```musi
static let counter := 0;
pinned buffer as p (...);
comptime let bits := 64;
```

## Staging

Valid:

```musi
let expr := ~(x + y);
let knownExpr := known ~(x + y);

let rhs := known ~(y * 2n32);
let expr2 := known ~(x + ~rhs);

splice known deriveShow[EnemySpec]();
```

Invalid:

```musi
#(x + y)        -- this is datum tuple syntax, not syntax quote
$(x + y)        -- $ belongs to template interpolation
quote(x + y)    -- not the locked staging syntax
```

## Any / Unknown / Empty

Valid:

```musi
let value : Any := host.config.get("health");
let health : ?Nat32 := value :?> Nat32;
let required : Nat32 := value :> Nat32;
```

Invalid by default:

```musi
let add(x, y) := x + y;   -- if unresolved types silently become Any
```

The same surface form is valid when types are solved by evidence/inference. The invalid part is implicit fallback to `Any`.

## Spread and datum sequence

Valid:

```musi
let args := #[1n32, 2n32];
callScript(fn, args);
add(args...);
```

Meaning:

```text
args      is one sequence value
args...   spreads elements into argument positions
```

Invalid inference:

```text
#[Any] is not the spread operator.
```

## Imports

Valid:

```musi
let math := import "std/math";
let engine := import "host/engine";
```

Invalid:

```musi
import std.math;
module game.enemy;
```
