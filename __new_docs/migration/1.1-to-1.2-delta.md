# Migration Delta: 1.1 to 1.2

Status: migration note.

## Terminology changes

```text
static -> fixed
pinned -> pin
Dynamic -> Any
Never/bottom wording -> Empty
```

`Unknown` is introduced as checker/frontend imprecision and must not appear in verified SEIL/SEBC.

## Staging additions

The following are locked:

```text
~       syntax quote / in-template splice
splice  source-position insertion
known   phase marker for compiler-known evaluation
```

Runtime syntax values are allowed when runtime syntax/compiler support exists.

## VM platform additions

The stack is now explicitly:

```text
Musi Core -> SEIL -> SEBC -> SEAM
```

SEIL/SEBC concrete syntax and binary encoding remain deliberately unspecified in 1.2.

## Embedded-safety additions

A new rejection checklist is added in `specs/24-embedded-systems-acceptance-checklist.md`.

Hidden `Any`, hidden allocation, hidden dynamic dispatch, and unresolved `Unknown` are rejection triggers.
