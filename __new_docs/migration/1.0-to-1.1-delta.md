# 1.0 Candidate to 1.1 Addendum Delta

Status: migration/reference note.

## Source name changes

Raw pointer source names change:

```text
Ptr[T]       -> RawPtr[T]
Ptr[mut T]  -> RawPtr[mut T]
```

## New source-level type names

```text
Root[T]
Host[T]
```

`Root[T]` is for stable VM-owned tokens to Musi-managed values.

`Host[T]` is for host-owned resources, objects, services, or values exposed to Musi.

## Existing syntax retained

Attributes remain:

```text
@name
@name(...)
```

FFI remains declaration-based:

```text
@foreign(...)
```

There is still no `foreign` keyword and no foreign block syntax.

Imports remain `let`-bound:

```musi
let name := import "path";
```

`opaque` and `erased` keep their existing meanings.

## New semantic chapters

The addendum adds formal semantics for:

- Generational Immix memory assumptions;
- `unsafe` vs `pin` separation;
- host interop vs raw FFI;
- `Root[T]` and `Host[T]`;
- retention groups;
- external layout contracts;
- externally laid-out field admissibility;
- raw callback entry constraints;
- VM obligations for roots, pins, barriers, thread entry, and boundary failure.
